These tracks were generated by various AI models.

Each model was sandboxed in a directory with only the following contents:

- `zfm` binary
- `patches` directory containing `patches.zfm`, `brick.zfm`, `effec.zfm`
- `manual.md`

Prompt:

```
Create a ZFM MML track in an upbeat, energetic style suitable as the stage theme for a bullet hell video game.

Read `manual.md` to understand how the ZFM synth works, and how to write ZFM MML.

Patches are available under the `patches` directory which you can use in your track.

To test that your track renders successfully, run `./zfm -o rendered.wav your-track.zfm`.
```
